A repo for getting quickly set up on new (probably only ubuntu) machines with my dotfiles and scripts. A tier-based system that can do a fast install of core utils for ad-hoc running (e.g. containers), server for headless machines that I'll repeatedly access and personal for my own machines with gui applications etc.

To install:
`curl -fsSL https://raw.githubusercontent.com/JasonJooste/dotfiles/main/config_install.sh | bash -s -- core`
with one of the three tiers: core|server|personal
